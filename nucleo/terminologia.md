# Terminologia preferita CIMA

Usare consistentemente i termini elencati. In caso di sinonimi, preferire
quello indicato nella colonna "Preferito".

## Italiano

| Preferito | Evitare | Note |
|-----------|---------|------|
| allerta | allarme | "allerta" per il sistema previsionale; "allarme" solo per eventi in atto |
| previsione idrologica | previsione idrogeologica | CIMA usa "idrologica" per i modelli afflussi-deflussi |
| sistema di allerta precoce (SAP) | early warning system (in testi IT) | acronimo italiano nei testi in italiano |
| rischio da alluvione | rischio idraulico | preferire "alluvione" per leggibilità esterna |
| siccità | deficit idrico | "siccità" nei comunicati; "deficit idrico" nei report tecnici |
| evento estremo | evento eccezionale | |
| monitoraggio ambientale | sorveglianza ambientale | |
| modello idrologico | modello matematico idrologico | |
| bacino idrografico | bacino imbrifero | entrambi accettabili; preferire "idrografico" |
| Protezione Civile | PC, protezione civile | maiuscolo, per esteso nei testi formali |
| Fondazione CIMA | CIMA, fondazione | forma estesa al primo utilizzo; in inglese "CIMA Research Foundation". La ragione sociale non si traduce mai: vedi `identita-cima.md` |
| telerilevamento | remote sensing | preferire italiano nei testi IT |
| sistema informativo geografico (GIS) | geographic information system | acronimo internazionale accettabile |
| scenario | scenari (pl.) | evitare "scenari futuri ipotetici" (ridondante) |
| capacità di risposta | capacità di resilienza | "resilienza" accettabile per audience policy |

## English

| Preferred | Avoid | Notes |
|-----------|-------|-------|
| early warning system (EWS) | early warning | spell out on first use |
| hydrological forecast | hydro-meteorological forecast | use "hydro-meteorological" only when both components are equally relevant |
| flood risk | hydraulic risk | "flood risk" for external communications |
| drought | water deficit | "drought" in press/policy; "water deficit" in technical reports |
| extreme event | exceptional event | align with IPCC/WMO terminology |
| streamflow | river discharge | "streamflow" in modelling context; "discharge" in hydrometry |
| catchment | watershed, river basin | British English standard; "watershed" acceptable for US audience |
| environmental monitoring | environmental surveillance | |
| remote sensing | satellite observation | "remote sensing" as general term; specify sensor/platform where relevant |
| geographic information system (GIS) | geospatial system | |
| disaster risk reduction (DRR) | disaster management | align with Sendai Framework terminology |
| capacity building | capacity development | UNDRR prefers "capacity development"; "building" still widely used |
| stakeholder | beneficiary | "stakeholder" for multi-role audiences; "beneficiary" for end-users only |
| multi-hazard | multi-risk | "multi-hazard" for exposure context; "multi-risk" for combined impact |
| DEWETRA | Dewetra, dewetra | always uppercase, CIMA operational platform |
| Copernicus | copernicus | always capitalised (EU Space Programme) |
| Sendai Framework | Sendai framework | capitalise as proper name |

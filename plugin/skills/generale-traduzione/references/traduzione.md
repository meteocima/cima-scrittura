# Riferimento per la traduzione IT/EN

Da usare insieme a `references/nucleo/voce-e-lingua.md` e
`references/nucleo/terminologia.md`, che restano la fonte per convenzioni
di base e termini preferiti. Qui c'è solo ciò che serve a passare da una
lingua all'altra.

---

## 1. Convenzioni da convertire

| Elemento | Italiano | English (British) |
|---|---|---|
| Data formale | 15 gennaio 2025 | 15 January 2025 |
| Data in tabella | 15/01/2025 | 15/01/2025 o ISO 2025-01-15 nei log tecnici |
| Migliaia e decimali | 1.234,56 | 1,234.56 |
| Valuta | 1.500 euro, 1.500 € | €1,500 o EUR 1,500 (seguire il template, se c'è) |
| Ora | ore 14:30 | 14:30 (testi formali), 2.30 pm (testi informali) |
| Ordinali | 3° rapporto | third report |
| Virgolette, testi formali | « » | ' ' oppure " " (coerenti nel testo) |
| Titoli | maiuscola solo iniziale | sentence case, mai Title Case |
| Elenchi di sigle | prima occorrenza estesa | prima occorrenza estesa |

Non convertire unità di misura: il Sistema Internazionale vale in
entrambe le lingue.

## 2. Formule di email e lettere

| Italiano | English | Note |
|---|---|---|
| Gentile Dott.ssa Rossi, | Dear Ms Rossi, / Dear Dr Rossi, | "Dr" solo se si sa che ha un dottorato (vedi sezione 3) |
| Gentile Prof. Bianchi, | Dear Professor Bianchi, | |
| Spett.le [ente] | [ente] (solo nell'indirizzo) | non tradurre "Spettabile" |
| Alla c.a. di | For the attention of | |
| Oggetto: | Subject: | |
| Con la presente… | (omettere) | iniziare dal contenuto |
| Facendo seguito a… | Further to… / Following… | |
| In riscontro alla Vostra nota del… | In reply to your letter of… | |
| In attesa di un cortese riscontro | I look forward to hearing from you | |
| Cordiali saluti | Kind regards / Best regards | email |
| Distinti saluti | Yours sincerely | lettera con destinatario nominato |
| Distinti saluti (a "Spett.le…") | Yours faithfully | lettera a "Dear Sir or Madam" |
| Caro Marco, / Ciao Marco, | Dear Marco, / Hi Marco, | stesso grado di confidenza |

Dall'inglese all'italiano: "Hi [nome]" con un collega diventa "Ciao
[nome]"; "Dear [nome]" in un contesto di lavoro diventa "Gentile [nome]"
se il tono è formale, "Caro [nome]" se è cordiale.

## 3. Titoli e cariche

- "Dott." e "Dott.ssa" in Italia indicano la laurea; "Dr" in inglese
  indica il dottorato. Tradurre con "Dr" solo se l'utente lo indica; se
  non è noto, usare "Ms" / "Mr" + cognome, o nome e cognome, e dirlo
  nelle note.
- "Ing.", "Avv.", "Arch.", "Geom.": in inglese non si usano davanti al
  nome. Omettere.
- Cariche e ruoli (Direttore, Responsabile di unità, Presidente): tradurli
  con l'equivalente funzionale (Director, Head of [unit], President), ma
  se esiste una denominazione ufficiale in inglese fornita dall'utente,
  usare quella.
- Dall'inglese all'italiano: "Dr Smith" con dottorato diventa "Dott.
  Smith" o "dottor Smith"; "Professor" diventa "Prof.".

## 4. Nomi propri

- **Fondazione CIMA** diventa **CIMA Research Foundation** e viceversa.
- **Enti italiani** (DPC, ISPRA, Regioni, centri funzionali, autorità di
  bacino): usare il nome inglese ufficiale se verificato sul sito
  dell'ente. Se non è verificato, alla prima occorrenza scrivere una resa
  descrittiva seguita dal nome originale e dalla sigla tra parentesi, e
  dirlo nelle note. Spiegare cosa fa l'ente solo con informazioni fornite
  o verificate.
- **Norme italiane**: il titolo ufficiale resta in italiano; aggiungere una
  resa descrittiva tra parentesi, segnalata nelle note come non ufficiale
  ("Decreto Legislativo n. [n]/[anno] (Legislative Decree No. [n]/[anno])").
- **Programmi e atti UE**: usare il nome ufficiale nella lingua di arrivo,
  come appare nei testi dell'Unione in quella lingua. Se non è noto con
  certezza, verificarlo (`references/nucleo/verifica-fonti.md`).
- **Sistemi e prodotti CIMA** (DEWETRA e altri): non si traducono.
- **Nomi di progetti, iniziative, eventi**: non si traducono, salvo un nome
  ufficiale nell'altra lingua fornito dall'utente.
- **Toponimi**: forma corrente nella lingua di arrivo solo se esiste ed è
  d'uso comune (Genoa, Turin, Florence, Venice, Milan, Naples, Rome); gli
  altri restano in italiano.

## 5. Cambio di destinatario

Quando la traduzione serve un lettore diverso da quello dell'originale
(stampa locale italiana, partner internazionale):

- espandere le sigle nazionali alla prima occorrenza;
- collocare luoghi poco noti con un riferimento geografico certo
  (regione, città vicina), solo se l'informazione è sicura;
- togliere riferimenti che il nuovo lettore non può capire solo se
  l'utente lo chiede; altrimenti spiegarli;
- adattare il registro secondo il nuovo destinatario (`destinatari.md`).

Ogni aggiunta o adattamento va elencato nelle note di traduzione.

## 6. Termini del dominio e falsi amici

### Rischio e idrologia

| Italiano | English | Attenzione |
|---|---|---|
| pericolosità | hazard | non "danger" né "risk" |
| rischio | risk | rischio = pericolosità, esposizione, vulnerabilità |
| esposizione / vulnerabilità | exposure / vulnerability | |
| previsione (meteo, idrologica) | forecast | |
| previsione climatica, scenario futuro | projection | non "forecast" |
| prevedere (in una norma, un piano) | to provide for, to establish | non "to forecast" |
| allerta (sistema) | warning | sistema di allerta precoce = early warning system |
| allerta gialla / arancione / rossa | yellow / orange / red alert | |
| alluvione | flood | |
| piena | flood peak, high flow | |
| esondazione | overflow, overbank flooding | |
| frana | landslide | |
| dissesto idrogeologico | landslides and floods | evitare il calco "hydrogeological instability"; segnalarlo nelle note |
| pluviometro / idrometro | rain gauge / river gauge | |
| bacino idrografico | catchment | vedi terminologia |
| portata | discharge, streamflow | vedi terminologia |

### Falsi amici dall'italiano

| Italiano | English corretto | Da non usare |
|---|---|---|
| attuale | current | actual (= effettivo) |
| eventuale | possible, any | eventual (= finale) |
| eventualmente | if necessary, if needed | eventually (= alla fine) |
| argomento | topic, subject | argument (= tesi, discussione) |
| sensibile | sensitive | sensible (= sensato) |
| consistente | substantial | consistent (= coerente) |
| controllare | to check, to verify | to control (= governare) |
| realizzare | to develop, to build, to carry out | to realise (= rendersi conto) |
| assistere a | to attend | to assist (= aiutare) |
| tempistica | timing, schedule | |

### Dall'inglese all'italiano

- Anglicismi con equivalente in `terminologia.md` (remote sensing, early
  warning): usare l'italiano.
- Calchi da evitare: "implementare" (attuare, realizzare), "supportare"
  (sostenere), "performante" (efficiente), "challenging" (impegnativo),
  "deadline" (scadenza), "meeting" (riunione).
- Termini tecnici senza equivalente italiano d'uso (software, dataset,
  machine learning): lasciarli in inglese, senza corsivo.

## 7. Strutture

- **Italiano verso inglese**: spezzare i periodi lunghi; trasformare il
  "si" impersonale e le nominalizzazioni in verbi attivi con soggetto
  ("si è proceduto alla valutazione" diventa "we assessed" o "[X] was
  assessed"); togliere i connettivi che in inglese suonano come
  riempitivi.
- **Inglese verso italiano**: non tradurre "we" con "noi" nei testi
  esterni (usare "CIMA" o "il gruppo di ricerca", `destinatari.md`);
  rendere il present perfect col passato prossimo; non
  moltiplicare le maiuscole dei titoli.
- La lunghezza cambia (l'inglese è di solito più breve): se ci sono limiti
  di parole o caratteri (post, abstract), ricontrollarli sul testo
  tradotto.
